# @karowanorg/orc-ui

orc monitor: live SSE run pages and self-contained static report.html.

Runtime extensions can contribute bounded declarative presentations through
the core `ExtensionLeaf.present` contract and live `context.present(...)`
updates. The same renderer handles live and
static views. Approval requests may also define named actions with optional
message fields; approvals without actions retain the standard allow/deny UI.

Part of orc - model-authored promise-native agent programs with deterministic replay, live monitoring, and pluggable harnesses. See the orc repository README for the full picture.
